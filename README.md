Entry for the [make.fun](https://make.fun) bounty
[Two-Sentence Horror](https://make.fun/c/u-suroto-two-sentence-horror-acea9253).

Exactly two sentences; the second reframes the first — the comfort of the first sentence becomes the dread of the second, and the horror is implied, never explained.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> I finally taught my smart speaker to say goodnight back. Tonight it whispered goodnight from inside the walls, in my dead mother's voice.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
